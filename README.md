# Barbearia Classic – Landing Page

A modern and responsive landing page for a barbershop, focused on fast booking, clear presentation of services and prices, and a highlighted location section.

## Features

- **Responsive layout** (mobile-first), optimized for different screen sizes  
- **Sticky header** with navigation links to all sections of the page  
- **Desktop navigation** with inline menu  
- **Mobile navigation** with:
  - Hamburger button that toggles the menu
  - Icon changes from hamburger to **X** when the menu is open
  - Menu automatically closes when a navigation link is clicked
- **Hero section** with a strong call-to-action for booking an appointment  
- **Services section** with cards describing the main barbershop services  
- **Pricing section** with clear and simple plans  
- **FAQ section** using collapsible items (accordion style)  
- **Contact section** with a primary CTA and social/contact icons  
- **Location section** highlighting the barbershop address and contact details  
- **Floating “Book Now” button** fixed at the bottom-right corner on all screens  

## Tech Stack

- **HTML5**
- **Tailwind CSS** (via CDN)
- **JavaScript** (vanilla) for mobile menu behavior
- **Google Fonts** (Work Sans)
- **Material Symbols** (icon font)
